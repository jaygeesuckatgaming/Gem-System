Music Recognition Help
=========================

This section contains settings for the music recognition feature.

The main purpose of this feature is to listen to the audio input and identify any music playing.

Key Settings:
-   **enable:** Set to 'true' to activate the feature, or 'false' to disable it.
-   **api_key:** Enter your API key for the recognition service here.

Remember to click 'Save All Settings' at the bottom after making changes and then restart the MCP server.

If you have selected a device, lets say B1(If you are using VoiceMeeter)
